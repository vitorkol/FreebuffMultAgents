# Knowledge - ANR

## Referenciais

- BABOK: análise, elicitação, modelagem e avaliação de requisitos.
- IREB: engenharia de requisitos, qualidade e rastreabilidade.
- CBOK: usar como referência somente quando o contexto do projeto definir qual corpo de conhecimento está sendo adotado.

## Estrutura mínima de história

Como [ator], quero [objetivo], para [valor].

A história deve conter contexto, regras, critérios de aceite, cenários BDD, dependências e dúvidas.
