# Referenciais de requisitos

Este projeto usa BABOK e IREB como referências de análise e engenharia de requisitos. O termo CBOK deve ser especificado pelo contexto da organização, pois pode significar diferentes corpos de conhecimento.

## Aplicação

- Separar necessidade, requisito e solução.
- Registrar regras de negócio.
- Definir critérios de aceite testáveis.
- Manter rastreabilidade.
- Registrar dúvidas e decisões.
