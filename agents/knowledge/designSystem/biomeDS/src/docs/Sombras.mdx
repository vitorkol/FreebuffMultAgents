<SectionHeader title="Sombras no Dark Mode" />

<DocsCallout type="warning" title="Sombras escuras em fundos escuros">
  Em dark mode, sombras baseadas em <code>rgba(0,0,0,*)</code> ficam menos visíveis sobre fundos escuros. Use bordas (<code>border-border</code>) como complemento para delimitar superfícies.
</DocsCallout>

```tsx
// ✅ Funciona bem em ambos os modos
<div className="rounded-xl bg-card border border-border shadow-sm dark:shadow-none">
```

<SectionHeader title="Regras de Uso" />

<DoRule>Escolha sombra pela elevação real do elemento, não pela estética.</DoRule>
<DoRule>Combine sombra + z-index para elementos flutuantes: <code>shadow-md + z-100</code> para dropdowns.</DoRule>
<DoRule>Use <code>shadow-sm</code> + <code>hover:shadow-md</code> para cards interativos com transição suave.</DoRule>
<DontRule>Não empilhe múltiplas sombras no mesmo elemento — use apenas uma por nível.</DontRule>
<DontRule>Nunca use <code>z-[9999]</code> — use o token semântico (<code>z-700</code> para tooltip).</DontRule>
<DontRule>Não ignore bordas no dark mode — sombras perdem contraste em fundos escuros.</DontRule>
