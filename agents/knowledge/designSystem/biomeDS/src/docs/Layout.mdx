<SectionHeader title="Regras de Uso" />

<DoRule>Sempre construa mobile-first: defina o estilo base para mobile e sobreponha para telas maiores.</DoRule>
<DoRule>Use o padrão de contêiner (<code>max-w-7xl mx-auto px-4 sm:px-6 lg:px-8</code>) em todas as seções de página.</DoRule>
<DoRule>Use os tokens de z-index semânticos — <code>z-400</code> para modais, <code>z-200</code> para sticky.</DoRule>
<DontRule>Não use <code>z-[9999]</code> — use sempre o token semântico correspondente.</DontRule>
<DontRule>Não construa desktop-first — requer <code>max-sm:</code> para sobrescrever e aumenta complexidade.</DontRule>
