<SectionHeader title="Padrões de Código" />

```tsx
// ✅ Card padrão
<div className="bg-card rounded-xl border border-border shadow-sm p-6">
  <h3 className="text-foreground font-semibold">Título</h3>
  <p className="text-muted-foreground text-sm">Descrição</p>
</div>

// ✅ Seção alternada
<section className="bg-section-gray py-15 md:py-30">...</section>

// ✅ Item de lista com hover
<li className="rounded-lg px-4 py-3 hover:bg-accent transition-colors cursor-pointer">
  {/* item */}
</li>

// ✅ Track completo de surface (Alert)
<div className="bg-success-surface border border-success-surface-border rounded-lg p-4">
  <p className="text-success-on-surface font-semibold">Sucesso</p>
</div>
```

<SectionHeader title="Regras de Uso" />

<DoRule>Use <code>bg-card</code> para todo conteúdo em cards — nunca <code>bg-white</code>.</DoRule>
<DoRule>Use <code>bg-section-gray</code> para alternar seções — mantém contraste em light e dark mode.</DoRule>
<DoRule>Use <code>bg-muted</code> para inputs desabilitados e áreas de rascunho.</DoRule>
<DontRule>Nunca use <code>bg-white</code> — use <code>bg-background</code> ou <code>bg-card</code>. <code>bg-white</code> quebra o dark mode.</DontRule>
<DontRule>Não misture preenchimento sólido (<code>bg-success</code>) com surface (<code>bg-success-surface</code>) no mesmo elemento de feedback.</DontRule>
