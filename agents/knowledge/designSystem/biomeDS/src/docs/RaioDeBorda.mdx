<SectionHeader title="Padrões de Código" />

```tsx
// ✅ Botão padrão
<button className="h-9 px-4 rounded-lg bg-primary text-white text-sm font-medium">
  Enviar
</button>

// ✅ Card
<div className="bg-card border border-border rounded-xl shadow-sm p-6">
  <h3>Título do Card</h3>
</div>

// ✅ Badge pill (status)
<span className="bg-success-surface text-success-on-surface text-xs px-2.5 py-0.5 rounded-full border border-success-surface-border">
  Concluído
</span>

// ✅ Input + Botão alinhados (mesmo rounded-lg)
<div className="flex gap-2">
  <input className="flex-1 h-9 rounded-lg border px-3 text-sm" />
  <button className="h-9 px-4 rounded-lg bg-primary text-white text-sm">
    Buscar
  </button>
</div>
```

<SectionHeader title="Regras de Uso" />

<DoRule>Use <code>rounded-lg</code> (8px) como raio padrão para botões e inputs.</DoRule>
<DoRule>Use <code>rounded-xl</code> (12px) para superfícies de conteúdo — cards, modais, sheets.</DoRule>
<DoRule>Use <code>rounded-full</code> para badges pill, chips e avatares circulares.</DoRule>
<DoRule>Elementos em grupo visual devem usar o mesmo raio — input e botão juntos, ambos <code>rounded-lg</code>.</DoRule>
<DontRule>Não misture raios diferentes dentro do mesmo componente sem razão estrutural.</DontRule>
<DontRule>Não use valores arbitrários como <code>rounded-[7px]</code> — use sempre um token da escala.</DontRule>
<DontRule>Não use <code>rounded-none</code> em componentes que participam de grupos com borda arredondada.</DontRule>
