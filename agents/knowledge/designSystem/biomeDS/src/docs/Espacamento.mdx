<SectionHeader title="Regras de Uso" />

<DoRule>Prefira sempre um valor da escala — evite classes arbitrárias como <code>gap-[18px]</code>.</DoRule>
<DoRule>Use tokens semânticos (<code>py-15 md:py-30</code>) para seções de página.</DoRule>
<DoRule>Mantenha consistência: se cards usam <code>p-6</code>, todos os cards do mesmo tipo devem usar <code>p-6</code>.</DoRule>
<DontRule>Não use valores ímpares (<code>p-[5px]</code>, <code>gap-[3px]</code>) — quebram a grade visual.</DontRule>
<DontRule>Não misture escalas de componente na mesma tela sem razão justificada.</DontRule>
