<SectionHeader title="Objetivo compartilhado" />

Os três componentes resolvem **entrada de dados** em formulários com:

- um **rótulo** opcional porém recomendado (`label`);
- **feedback** abaixo do controle (`helperText`);
- **validação visual e ARIA** (`hasError`);
- **densidade** compartilhada via escala de tamanho (`size` alinhado a `FieldSize` onde aplicável);
- **espaço para layout** do consumidor (`wrapperClassName`).

```tsx
import { Input, Textarea, Select } from "@biome/design-system"

// Shared field language: label, helperText, hasError, size, wrapperClassName
export function FieldExamples() {
  return (
    <>
      <Input
        label="Full name"
        placeholder="Jane Doe"
        size="md"
        helperText="As on your ID."
        hasError={false}
        wrapperClassName="gap-1"
      />
      <Textarea
        label="Notes"
        placeholder="Optional context…"
        size="md"
        helperText="Visible to reviewers."
        hasError={false}
      />
      <Select
        label="Status"
        placeholder="Choose status"
        size="md"
        helperText="Required for submission."
        hasError={false}
        options={[
          { value: "open", label: "Open" },
          { value: "done", label: "Done" },
        ]}
      />
    </>
  )
}
```

<SectionHeader title="Orientação para novos campos" />

<DoRule>Reutilize a escala <code>FieldSize</code> e os mesmos nomes de props da família quando o controle for equivalente a um campo de formulário.</DoRule>
<DoRule>Mantenha <code>aria-describedby</code> ligado ao texto de ajuda/erro e <code>aria-invalid</code> quando <code>hasError</code>.</DoRule>
<DontRule>Não crie um terceiro padrão visual para borda, raio e foco — alinhe ao Input como referência de campo.</DontRule>
