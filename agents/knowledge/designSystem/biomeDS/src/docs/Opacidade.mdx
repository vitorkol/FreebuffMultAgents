<SectionHeader title="Modificadores de Opacidade Tailwind" description="O Tailwind v4 suporta modificadores / em qualquer utilitário de cor — prefira este padrão a opacity-* quando quiser transparência em cores específicas." />

```tsx
// ✅ Modificador / — afeta apenas a cor, não os filhos
<div className="bg-primary/10">...</div>         // fundo com 10% de opacidade
<div className="border-destructive/30">...</div> // borda com 30%
<p className="text-foreground/70">...</p>         // texto com 70%

// ✅ Overlay de modal
<div className="fixed inset-0 bg-black/50 backdrop-blur-sm z-300" />
```

<SectionHeader title="Uso por Contexto" />

```tsx
// ✅ Elemento desabilitado
<button disabled className="opacity-50 cursor-not-allowed">Desabilitado</button>
// O Button do Biome aplica disabled:opacity-50 automaticamente

// ✅ Skeleton placeholder
<div className="animate-pulse bg-muted opacity-60 rounded-md h-4 w-full" />

// ✅ Animações de entrada/saída
.entering { opacity: 0; }
.entered  { opacity: 1; transition: opacity 200ms ease; }
```

<DocsCallout type="warning" title="Opacidade em texto">
  Para texto auxiliar e desabilitado, prefira tokens de cor semânticos (<code>text-muted-foreground</code>, <code>text-text-disabled</code>) em vez de <code>opacity-*</code>. Opacidade no texto pode confundir leitores de tela.
</DocsCallout>

<SectionHeader title="Regras de Uso" />

<DoRule>Use modificadores <code>/</code> para transparência em cores — <code>bg-primary/10</code> em vez de <code>opacity-10</code> no elemento pai.</DoRule>
<DoRule>Use <code>opacity-50</code> consistentemente para estado disabled.</DoRule>
<DoRule>Use <code>opacity-0</code> / <code>opacity-100</code> para animações de entrada e saída.</DoRule>
<DontRule>Não use <code>opacity-*</code> em texto para comunicar estado — use tokens de cor semânticos.</DontRule>
<DontRule>Não aplique opacidade em componentes que já gerenciam seu próprio estado disabled.</DontRule>
