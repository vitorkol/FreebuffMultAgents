<h2 style={{ color: 'var(--text-primary, #4c4d4d)' }}>O que é o Biome?</h2>

<div style={{ color: 'var(--text-primary, #4c4d4d)' }}>
  <p>
    O Biome é um conjunto unificado de <strong>componentes React</strong>, <strong>tokens de design</strong> e
    <strong> padrões documentados</strong> que orienta a criação das interfaces digitais do ecossistema <strong>SEMAD/PSEG</strong>.
    Ele promove:
  </p>

  <ul>
    <li><strong>Consistência</strong> visual entre telas e fluxos dos produtos consumidores</li>
    <li><strong>Acessibilidade</strong> como requisito, não opcional — conformidade mínima WCAG 2.1 AA</li>
    <li><strong>Produtividade</strong> — componentes prontos para casos de uso reais identificados no produto</li>
    <li><strong>Escalabilidade</strong> — tokens como única fonte de verdade para cores, tipografia e espaçamento</li>
  </ul>
</div>

<DocsCallout type="tip" title="Baseado em uso real">
  Cada componente do Biome nasceu de um padrão real identificado em produtos consumidores. Nenhum componente é especulativo — tudo tem origem em interfaces que já existem em uso.
</DocsCallout>
