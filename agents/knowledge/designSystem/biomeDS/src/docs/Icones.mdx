<SectionHeader title="Regras de Uso" />

<div style={{ display: 'grid', gridTemplateColumns: '1fr 1fr', gap: 12, marginBottom: 16 }}>
  <div>
    <DoRule>Use o componente Icon com prop name — não importe lucide-react diretamente.</DoRule>
    <DoRule>Use tokens de tamanho (sm, md, lg) para consistência visual.</DoRule>
    <DoRule>Mantenha tamanhos consistentes dentro do mesmo contexto.</DoRule>
    <DoRule>Adicione aria-label quando o ícone transmite informação sem texto associado.</DoRule>
  </div>
  <div>
    <DontRule>Não importe ícones diretamente de lucide-react em código consumidor.</DontRule>
    <DontRule>Não misture bibliotecas de ícones (Bootstrap Icons, FontAwesome, etc.).</DontRule>
    <DontRule>Não use tamanhos menores que xs (14px) — perdem legibilidade.</DontRule>
    <DontRule>Não use ícone como única forma de comunicar informação crítica sem texto alternativo.</DontRule>
  </div>
</div>

<DocsCallout type="tip" title="Catálogo completo">
  O Biome inclui automaticamente todos os ícones do Lucide. Procure qualquer ícone em <a href="https://lucide.dev/icons" target="_blank" rel="noopener noreferrer" style={{ color: '#264c37', fontWeight: 600 }}>lucide.dev/icons</a>, copie o nome kebab-case, e use diretamente como <code>{`<Icon name="..." />`}</code>.
</DocsCallout>
