## Arquitetura

O sistema de cores opera em duas camadas:

1. **Paleta bruta** — valores hex fixos em `:root` (ex: `#198754`)
2. **Tokens semânticos** — CSS custom properties que referenciam a paleta e respondem ao dark mode

```
Paleta bruta (hex)  →  Token CSS var      →  Utilitário Tailwind  →  Componente
    #198754         →  --success          →  bg-success           →  <Button variant="success">
    #f0fdf4         →  --success-surface  →  bg-success-surface   →  <Alert intent="success">
```

<SectionHeader title="Regras de Uso" />

<DoRule>Use o token mais semântico disponível — <code>text-muted-foreground</code> em vez de <code>text-gray-500</code>.</DoRule>
<DoRule>Para feedback, use o track surface (suave) em alerts/badges e o token sólido em botões/ícones preenchidos.</DoRule>
<DoRule>Ative o dark mode via classe <code>dark</code> no elemento <code>html</code> — todos os tokens respondem automaticamente.</DoRule>
<DontRule>{'Nunca use hex diretamente em componentes — ex: style={{ backgroundColor: "#f0fdf4" }}. Use tokens semânticos.'}</DontRule>
<DontRule>Nunca misture tokens de surface e tokens sólidos no mesmo elemento de feedback.</DontRule>
