# Toast

Notificação não-bloqueante que aparece temporariamente para informar o usuário sobre o resultado de uma ação. Construído sobre o Sonner, suporta variantes (success, error, warning, info) e botões de ação opcionais.

<SectionHeader title="Acessibilidade" />

- Toasts utilizam `role="status"` e `aria-live="polite"` para mensagens não-críticas, anunciadas sem interromper o usuário.
- Toasts de erro devem usar `aria-live="assertive"` para garantir que leitores de tela anunciem imediatamente.
- Botões de ação dentro de toasts devem ser acessíveis via teclado (Tab + Enter/Space).
- Toasts são automaticamente descartados após um tempo — não use para informações que exigem confirmação do usuário.

<SectionHeader title="Boas Práticas" />

<DoRule>Mantenha mensagens curtas e objetivas. Use a variante correta para o tipo de feedback.</DoRule>
<DoRule>Forneça uma ação de "Desfazer" quando a operação for reversível.</DoRule>

<DontRule>Não use toasts para informações críticas que exigem confirmação — use Dialog nesses casos.</DontRule>
<DontRule>Não empilhe mais de 3 toasts simultaneamente — pode sobrecarregar o usuário.</DontRule>
