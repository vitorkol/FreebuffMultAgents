- **primary** — Ação principal da tela (ex: Salvar, Enviar)
- **secondary** — Ação secundária com borda da marca
- **ghost** — Ação terciária, sem fundo até hover
- **outline** — Ação alternativa com borda neutra
- **danger** — Ação destrutiva (ex: Excluir, Cancelar)
- **link** — Aparência de link, sem padding vertical

<SectionHeader title="Acessibilidade" />

- **Navegação por teclado** — O botão recebe foco via Tab e é acionado por Enter ou Space
- **Estados de foco** — Anel de foco visível (`focus-visible:ring-2`) indica foco vindo do teclado
- **aria-busy** — Durante loading, o componente define `aria-busy="true"` para leitores de tela
- **Desabilitado** — Quando `disabled` ou `loading`, o botão não recebe foco e não é acionável
- **Ícones decorativos** — Ícones adicionados via `iconLeft`/`iconRight` são automaticamente decorativos (`aria-hidden`)

<SectionHeader title="Boas práticas" />

<DoRule>Use variant="primary" para a ação principal de cada contexto (formulário, modal, página).</DoRule>
<DoRule>Use variant="danger" apenas para ações irreversíveis ou destrutivas.</DoRule>
<DoRule>Use loading para indicar que uma ação assíncrona está em andamento.</DoRule>
<DoRule>Combine iconLeft ou iconRight com texto descritivo para clareza.</DoRule>
<DoRule>Use nomes de ícone em kebab-case diretamente como string: `iconLeft="search"`</DoRule>

<DontRule>Não use múltiplos botões primary na mesma área — destaque apenas uma ação principal.</DontRule>
<DontRule>Não use variant="link" para ações que não navegam — prefira ghost ou outline.</DontRule>
<DontRule>Não oculte o loading — sempre mostre feedback visual durante operações assíncronas.</DontRule>
<DontRule>Não use ícones como único conteúdo em botões de ação — adicione texto ou aria-label.</DontRule>
<DontRule>Não importe ícones diretamente de lucide-react — use props string como iconLeft="search".</DontRule>
