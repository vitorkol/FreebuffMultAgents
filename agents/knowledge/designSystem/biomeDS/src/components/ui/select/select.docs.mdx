# Select

Campo de seleção única pronto para uso em produtos, com API de alto nível alinhada ao padrão de campo do `Input` (`label`, `size`, `startIcon`, `endIcon`, `helperText`, `hasError`, `items/options`). Também expõe primitivos composicionais para cenários avançados.

<SectionHeader title="Uso recomendado (API simples)" />

```tsx
<Select
  label="Categoria"
  placeholder="Selecione uma opção"
  items={[
    { value: "service", label: "Serviço" },
    { value: "support", label: "Suporte" },
  ]}
/>
```

<DoRule>Prefira <code>items</code> (ou <code>options</code>) no uso diário. O Biome já monta trigger e lista com acessibilidade.</DoRule>

<SectionHeader title="Acessibilidade" />

- Navegação completa por teclado: setas para cima/baixo navegam entre opções, Enter seleciona, Escape fecha o dropdown.
- Utiliza roles ARIA apropriados (`listbox`, `option`) gerenciados automaticamente pelo Radix UI.
- O gerenciamento de foco é feito pelo Radix — o foco retorna ao trigger ao fechar.
- Associe a um `<label>` para garantir que leitores de tela identifiquem o propósito do campo.

<SectionHeader title="Boas Práticas" />

<DoRule>Forneça um placeholder claro que indique o tipo de seleção esperada.</DoRule>
<DoRule>Mantenha o texto das opções conciso. Agrupe com separadores quando a lista for extensa.</DoRule>

<DontRule>Não use para menos de 3 opções — prefira Radio para listas curtas.</DontRule>
<DontRule>Não use para cenários de seleção múltipla — o Select é exclusivamente para seleção única.</DontRule>
