<SectionHeader title="Acessibilidade" />

- Utiliza o elemento nativo `<textarea>`, herdando toda a semântica e comportamento de teclado do navegador.
- Sempre associe um `<label>` externo ao Textarea, ou forneça `aria-label` para contexto acessível.
- Textareas desabilitados (`disabled`) não são focáveis via teclado, seguindo o comportamento padrão do HTML.
- Quando usado em formulários, certifique-se de que mensagens de erro estejam vinculadas via `aria-describedby`.

<SectionHeader title="Boas Práticas" />

<DoRule>Sempre forneça um label visível ou acessível para o campo.</DoRule>
<DoRule>Defina um número de linhas (`rows`) ou altura mínima adequado ao conteúdo esperado.</DoRule>

<DontRule>Não use Textarea para entrada de linha única — use Input nesse caso.</DontRule>
<DontRule>Não desabilite o redimensionamento (`resize-none`) sem uma justificativa clara de design.</DontRule>
