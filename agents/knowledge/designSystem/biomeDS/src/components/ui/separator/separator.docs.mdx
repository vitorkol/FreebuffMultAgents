<SectionHeader title="Acessibilidade" />

- Utiliza `role="separator"` por padrão, comunicando a divisão semântica para leitores de tela.
- Para separadores puramente decorativos, defina a prop `decorative` como `true` — isso remove o role da árvore de acessibilidade.
- Separadores verticais utilizam `aria-orientation="vertical"` automaticamente.
- Não exige interação do usuário — é um elemento não-focável.

<SectionHeader title="Boas Práticas" />

<DoRule>Use para criar ritmo visual entre seções de conteúdo dentro de cards, listas e painéis.</DoRule>
<DoRule>Use a orientação vertical em toolbars e layouts inline para separar ações adjacentes.</DoRule>

<DontRule>Não abuse de separadores — espaçamento em branco (white space) pode ser suficiente para criar hierarquia visual.</DontRule>
<DontRule>Não use como substituto estrutural para containers de layout — separadores são elementos visuais, não organizacionais.</DontRule>
