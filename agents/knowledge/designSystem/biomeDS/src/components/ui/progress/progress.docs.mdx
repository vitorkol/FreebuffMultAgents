<SectionHeader title="Acessibilidade" />

- Utiliza `role="progressbar"` com `aria-valuenow`, `aria-valuemin` e `aria-valuemax` automaticamente via Radix UI.
- Sempre forneça um label visível ou `aria-label` descrevendo o que está em progresso (ex.: "Upload de arquivo").
- Leitores de tela anunciam o valor atual como porcentagem — mantenha o `value` atualizado com precisão.
- Evite remover o componente abruptamente ao completar; prefira transicionar para um estado de "concluído" antes.

<SectionHeader title="Boas Práticas" />

<DoRule>Sempre forneça contexto sobre o que o progresso representa — use um label visível junto à barra.</DoRule>
<DoRule>Use transições animadas para atualizações em tempo real, melhorando a percepção de responsividade.</DoRule>

<DontRule>Não use a barra de progresso para carregamentos indeterminados — use Spinner em vez disso.</DontRule>
<DontRule>Não deixe a barra de progresso sem um label — o usuário precisa saber o que está sendo processado.</DontRule>
