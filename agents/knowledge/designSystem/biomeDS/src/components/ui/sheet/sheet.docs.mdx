# Sheet

Painel deslizante para fluxos secundários de produto, como filtros, formulários curtos e detalhes contextuais, sem quebrar o contexto da tela atual.

<ComponentOverviewCard
  category="Overlay"
  aria="Gerenciamento automático de foco (focus trap)"
  file="src/components/ui/sheet/sheet.tsx"
  darkMode="Automático via tokens"
/>

- **Primitivo base** — `@radix-ui/react-dialog`.
- **Caminho recomendado** — `SheetPanel` (API declarativa plug-and-play).
- **Escape hatch** — composição com `Sheet`, `SheetContent`, `SheetHeader`, `SheetFooter`.
- **Fechamento** — suporta `Escape`, overlay e botão de fechar.

<SectionHeader title="Dois níveis de API" />

#### `SheetPanel` — uso recomendado

```tsx
<SheetPanel
  trigger={<Button>Abrir painel</Button>}
  title="Editar perfil"
  description="Atualize os dados e salve."
  side="right"
  footer={
    <>
      <SheetClose asChild><Button variant="outline">Cancelar</Button></SheetClose>
      <Button>Salvar</Button>
    </>
  }
>
  <Input label="Nome" />
</SheetPanel>
```

#### Primitives — composição avançada

```tsx
<Sheet>
  <SheetTrigger asChild><Button>Abrir</Button></SheetTrigger>
  <SheetContent side="right">
    <SheetHeader>
      <SheetTitle>Título</SheetTitle>
      <SheetDescription>Descrição</SheetDescription>
    </SheetHeader>
    <SheetFooter>...</SheetFooter>
  </SheetContent>
</Sheet>
```

<SectionHeader title="Quando usar" />

<DoRule>Use para edição lateral de dados sem perder o contexto da página atual.</DoRule>
<DoRule>Use para filtros de listagens e ajustes rápidos de parâmetros.</DoRule>
<DoRule>Use para detalhes complementares que não exigem navegação dedicada.</DoRule>

<SectionHeader title="Quando não usar" />

<DontRule>Não use para confirmações destrutivas críticas — prefira `Dialog`.</DontRule>
<DontRule>Não use para fluxos longos/multi-step complexos — prefira página dedicada.</DontRule>
<DontRule>Não use para menus simples de ação — prefira `DropdownMenu` ou `Popover`.</DontRule>

---

<SectionHeader title="Acessibilidade" />

- O foco é preso dentro do painel enquanto aberto (focus trap).
- O foco retorna para o trigger ao fechar.
- `role="dialog"` e `aria-modal="true"` são aplicados pelo Radix.
- `SheetTitle` e `SheetDescription` alimentam `aria-labelledby` e `aria-describedby`.
