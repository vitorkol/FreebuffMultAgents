# Dropdown Menu

Menu contextual acionado por um botão que exibe uma lista de ações ou opções. O uso recomendado no Biome é declarativo via `trigger` + `items` + `onAction`, mantendo composição avançada para casos especiais.

<SectionHeader title="Uso recomendado (API simples)" />

```tsx
<DropdownMenu
  trigger={<Button variant="outline">Open Menu</Button>}
  label="My Account"
  items={[
    { id: "profile", label: "Profile", icon: "user" },
    { id: "settings", label: "Settings", icon: "settings" },
    { id: "logout", label: "Logout", icon: "log-out", destructive: true, separatorBefore: true },
  ]}
  onAction={(id) => console.log(id)}
/>
```

<DoRule>Prefira a API declarativa para manter consistência de interação e acessibilidade em produto.</DoRule>

<SectionHeader title="Acessibilidade" />

- **Roles** — O menu usa `role="menu"` e cada item usa `role="menuitem"` (ou `role="menuitemcheckbox"` para itens checkbox), seguindo o padrão WAI-ARIA de menu.
- **Navegação por teclado** — Setas movem o foco entre itens, `Enter` ou `Space` ativa o item focado, e `Escape` fecha o menu retornando o foco ao trigger.
- **Captura de foco** — Enquanto o menu está aberto, o foco fica preso dentro dele para que `Tab` não saia do menu.
- **Trigger** — O botão trigger recebe `aria-haspopup="menu"` e `aria-expanded` automaticamente via Radix.

<SectionHeader title="Boas Práticas" />

<DoRule>Agrupe ações relacionadas usando DropdownMenuSeparator e DropdownMenuLabel para clareza.</DoRule>
<DoRule>Mostre atalhos de teclado via DropdownMenuShortcut quando a ação possui hotkey global.</DoRule>
<DoRule>Use DropdownMenuCheckboxItem para configurações togglable que se aplicam imediatamente.</DoRule>

<DontRule>Não use DropdownMenu para seleção de campo de formulário — use o componente Select.</DontRule>
<DontRule>Não aninhe submenus em mais de um nível — aninhamento profundo prejudica a descoberta e usabilidade mobile.</DontRule>
<DontRule>Não posicione ações destrutivas sem diferenciação visual — use cor de perigo ou grupo separado.</DontRule>
