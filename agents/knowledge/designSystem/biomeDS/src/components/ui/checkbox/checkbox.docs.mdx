# Checkbox

Controle de seleção que permite ao usuário alternar um valor booleano. Suporta rótulo, texto auxiliar, estado de erro, estado indeterminado e múltiplos tamanhos — ideal para formulários com opções não exclusivas.

<SectionHeader title="Acessibilidade" />

- Utiliza semântica nativa de `<input type="checkbox">` — funcionalidade completa de teclado sem JavaScript adicional.
- O rótulo é associado via `htmlFor`, garantindo que clicar no texto também alterne o checkbox.
- Mensagens de erro e texto auxiliar são vinculados via `aria-describedby` para leitores de tela.
- A tecla `Space` alterna o estado do checkbox quando focado. A navegação entre checkboxes é feita com `Tab`.

<SectionHeader title="Boas Práticas" />

<DoRule>Sempre forneça um rótulo visível. Use helperText para orientação adicional quando necessário.</DoRule>
<DoRule>Agrupe checkboxes relacionados com um fieldset e legend para contexto semântico.</DoRule>

<DontRule>Não use checkbox para opções mutuamente exclusivas — utilize Radio para esse caso.</DontRule>
<DontRule>Não oculte o rótulo do checkbox — ele é essencial para acessibilidade e usabilidade.</DontRule>
