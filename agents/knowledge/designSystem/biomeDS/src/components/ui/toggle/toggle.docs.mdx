Botão de dois estados que pode ser ativado ou desativado. Suporta variante outline e labels de texto. Construído sobre o Radix UI Toggle.

<SectionHeader title="Acessibilidade" />

- Utiliza `aria-pressed` para comunicar o estado atual (ativado/desativado) a tecnologias assistivas.
- Acessível via teclado com Enter e Space para alternar o estado.
- Sempre forneça `aria-label` descrevendo o que está sendo alternado, especialmente em toggles apenas com ícone.
- O estado visual ativo deve ter contraste suficiente para ser distinguido do estado inativo.

<SectionHeader title="Boas Práticas" />

<DoRule>Use para configurações ou preferências que entram em vigor imediatamente (ex: negrito, itálico).</DoRule>
<DoRule>Forneça feedback visual claro para o estado ativo, com contraste adequado.</DoRule>

<DontRule>Não use Toggle para escolhas binárias que precisam ser submetidas com o formulário — use Checkbox.</DontRule>
<DontRule>Não use Toggle sem um label claro (visual ou via `aria-label`).</DontRule>
