<SectionHeader title="Acessibilidade" />

- Badges são tipicamente decorativos — certifique-se de que a informação que eles transmitem também esteja disponível em texto ou via `aria-label` no elemento pai.
- Quando um badge é a única indicação de status (ex: "Online"), adicione contexto textual acessível como `aria-label` ou texto visually-hidden.
- Badges dispensáveis possuem um botão de fechar com `aria-label` adequado para ativação por teclado.
- Não dependa apenas de cor para transmitir significado — o texto do rótulo e/ou ícone devem ser suficientes.

<SectionHeader title="Boas Práticas" />

<DoRule>Use variantes semânticas (success, warning, danger) que correspondam ao significado real do status.</DoRule>
<DoRule>Mantenha o texto do badge curto — idealmente 1-2 palavras.</DoRule>

<DontRule>Não dependa exclusivamente de cor para comunicar informação — combine com texto e/ou ícones.</DontRule>
<DontRule>Não sobrecarregue uma única view com muitos badges — isso reduz o impacto visual de cada um.</DontRule>
